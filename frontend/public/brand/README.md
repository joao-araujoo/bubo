# Ativos oficiais do Bubo

Esta pasta aceita somente os arquivos oficiais da marca, preferencialmente com fundo transparente.

Arquivos esperados:

- `bubo-logo.png`: símbolo principal quadrado/transparente usado no header e nos fallbacks de marca;
- `bubo-wordmark.png`: versão horizontal opcional da marca;
- `bubo-mascot.png`: mascote oficial usado nos fluxos de IA.

Enquanto um arquivo não existir, a interface exibe apenas um fallback tipográfico neutro. O produto não desenha corujas nem recria a marca com SVG manual.

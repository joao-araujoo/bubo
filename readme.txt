O projeto consiste na inspiração do skoob, porém o leitor deve realizar
resenhas do que leu antes de conseguir salvar as novas páginas lidas,
estas sendo avaliadas por IA's treinadas para auxiliar na leitura
ativa e acabar de vez com a perda da memória dos livros que lemos pois com
esta aplicação, tornaria-mos melhores leitores.

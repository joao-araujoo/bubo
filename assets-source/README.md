# assets-source — official Bubo files (canonical)

These are byte-identical copies of the official files from `Bubo - Assets/`, renamed cleanly.
`manifest.json` lists each file's id, original name, pose label, size and SHA-256.

- Do not edit these files. `npm run assets:check` fails if any byte changes.
- App-ready copies are generated by `npm run assets:build` into `apps/mobile/assets/`.
- See `docs/brand-assets.md` for the full inventory, pose mapping and known gaps.

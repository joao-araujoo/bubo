# ADR-002 — Expo SDK 57 + Expo Router for the mobile app

- Status: Accepted
- Date: 2026-09-26

## Context

Bubo is a native iOS/Android product. The brief targets Expo SDK 57, React 19 and React Native
0.86, with typed routes, the New Architecture, portrait orientation and the id `com.joaoaraujo.bubo`.

## Decision

- Expo SDK 57 (`expo ~57.0.25`). Versions come from the SDK 57 template and the SDK's
  `bundledNativeModules.json`, not from "latest":
  - `react-native 0.86.3`
  - `react 19.2.3`
  - `react-native-reanimated 4.5.1`
  - `react-native-worklets 0.10.1`
  - `typescript ~6.0.3`
- npm's latest React Native is 0.87 and latest React is 19.3. We don't use them because SDK 57
  pins 0.86 / 19.2. This follows the SDK, not an arbitrary downgrade.
- Expo Router with file-based routes in `src/app`, and `experiments.typedRoutes` enabled.
- The New Architecture is the only architecture in SDK 57. The old `newArchEnabled` flag no
  longer exists in `ExpoConfig`, so there is nothing to set.
- Native-only: `platforms: ['ios', 'android']`. No react-dom or react-native-web.
- `app.config.ts` holds name, scheme, orientation, icons, splash and embedded fonts.
- `npx expo install --check` must report "Dependencies are up to date".
- The root `package.json` has `overrides` for `react`, `react-dom` (19.2.3) and
  `react-native-worklets` (0.10.1). Without them, npm auto-installs peer dependencies at their
  latest versions (React 19.3, worklets 0.13), which leaves the tree with two copies of React.
  That causes a runtime "Invalid hook call" in Metro. Bump the overrides together with the SDK.

## Consequences

- Upgrades happen one SDK at a time with `npx expo install --fix`.
- Native folders (`android/`, `ios/`) are generated by prebuild and gitignored (CNG).

## Alternatives considered

- **Bare React Native CLI:** more native maintenance and no config plugins.
- **React Navigation without Expo Router:** no file-based routes and no typed hrefs.
- **Latest React Native (0.87) outside the SDK:** unsupported combination for Expo modules.

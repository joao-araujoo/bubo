# Stitch design source

The full Stitch export was captured on 2026-09-25 and contains **87 folders**, including **64 named Bubo screens/states** plus source-asset folders and duplicate iterations.

The export's design system is titled **Tactile Cognitive Gamification**.

## Canonical visual direction
- App-first / mobile-first.
- Plus Jakarta Sans.
- Bubo Purple: `#7C3AED`.
- Deep Purple: `#5B21B6`.
- Purple Light: `#A78BFA`.
- Lavender background: `#F8F5FF`.
- Ink: `#21152F`.
- Success: `#2ECF73`.
- Warning: `#F5A524`.
- Error: `#EF5B5B`.
- Tactile 3D push-down buttons.
- 16px mobile gutters.
- 48px minimum touch target; 56px preferred for primary actions.
- Friendly high-radius cards, structural borders and short physical shadows.
- Mascot-driven feedback, but no generic AI aesthetic.

## Important
The exported HTML is **reference material**, not production React Native code.

Stitch produced duplicates and exploratory screens. The design export is a visual idea inventory, not an instruction to ship every frame in the MVP.

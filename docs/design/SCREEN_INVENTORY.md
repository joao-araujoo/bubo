## Duplicate iterations
Several exports have `_1` / `_2` variants. Before implementing a slice, choose the latest approved visual for that flow rather than carrying both forward.

## Rule
The approved Home/Hoje visual is the north star. The five primary destinations remain:

**Hoje · Estante · Revisar · Comunidade · Você**
